PHP 8.5 MySQL 8.4

Steps to start the project:

Clone the project to yourself
Copy .env.example to .env
Open a terminal in the project's root directory
Start docker if you didn't it before
Enter command in the terminal: docker compose up --build
The app will be available at http://localhost:8000
Database migrations will execute automatically

Url to get admin panel: http://localhost:8000/admin/panel
Credentials to admin panel:
username: admin
password: admin
